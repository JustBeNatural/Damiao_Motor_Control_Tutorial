# Kinematics 机器人运动学

1. 定义：一种动作科学，跟用了多大的力无关
2. 关键核心：动作(Velocity)，位置(Position)，加速度(Acceleration)，关节(Link)
3. D-H模型（Denavit–Hartenberg 参数法)
4. 用4个参数（a, d, θ, α）来描述两个相邻连杆坐标系之间的空间关系，把复杂机械臂拆成一节一节，每一节只用4个参数描述

| 参数     | 符号 | 物理含义                             | 测量基准          |
| -------- | ---- | ------------------------------------ | ----------------- |
| 连杆长度 | ai   | 沿 xi 轴，从 zi−1 到 zi 的距离       | 连杆本身结构      |
| 连杆扭角 | αi   | 绕 xi 轴，从 zi−1 旋转到 zi 的角度   | 连杆本身结构      |
| 关节偏距 | di   | 沿 zi−1 轴，从 xi−1 到 xi 的距离     | 关节变量 (移动副) |
| 关节角度 | θi   | 绕 zi−1 轴，从 xi−1 旋转到 xi 的角度 | 关节变量 (旋转副) |

也就是相当于从一个坐标系转到另一个坐标系，用四个动作参数变化就能做到，两个变量a,α形容连杆（角度和距离），两个变量d,θ形容关节的坐标系变化
