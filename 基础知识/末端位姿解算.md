# 末端位姿解算

# 1\.原理介绍

这里使用的四轴机械臂是串联机械臂，也就是所有关节和连杆都是一根绳一样连在一起的，

base\_link\-\-\-joint1\-\-\-link1\-\-\-joint2\-\-\-link2\-\-\-joint3\-\-\-link3\-\-\-joint4\-\-\-link4

所有的算法本质上都是数学

末端姿态解算的本质就是把末端的坐标位置转换为每一个电机自己的坐标轴位置，也就是每个电机的旋转角度位姿。而URDF在这个末端姿态解算算法的作用，本质上就是建立了一条完整的坐标变换链，每个电机定义了一次坐标系变换。

这是机器人运动学里机械臂坐标轴变换里的一个示意图，看不懂也没关系，反正在工程应用上只需要调包调参数就行，算法实现别人都已经写好了直接用就好。

在URDF文件中，joint的部分有几个子模块：

origin 定义子坐标系相对于父坐标系的初始变换

axis 定义关节旋转轴方向

joint angle 定义当前旋转角度

末端姿态通常有这6个参数组成: x, y, z, roll, pitch, yaw

# 2\.代码实现

最推荐的实现方式：直接用 ROS2 TF

ROS里面直接可以调包使用末端解算算法，需要先publish一个joint\_state节点，从 URDF 中读取每个关节的 origin 和 axis，再结合实时关节角 joint\_states 生成每个关节的齐次变换矩阵。通过从 base\_link 到 pen\_tip\_link 的矩阵连乘，即可得到末端执行器相对于基坐标系的位置和姿态。
