# 2026\-05\-29\_四轴机械臂复现位姿抖动

# 2026\-05\-29

## 问题描述：

尝试用ROS2订阅电机joint的state后，手动操作机械臂到三个点位，每个点位保持5s后程序自动记录数据，三个点位记录之后程序让机械臂回到最初点位，并重复刚刚的三个点位姿态。

采集点位数据过程中很顺利，但当程序执行复现三点位时会出现机械臂剧烈抖动的情况，但机械臂也确实会往目标点位移动。

猜测是不是URDF文件写的有问题，因为这个四轴机械臂的URDF是我用之前的三轴机械臂URDF和网上开源的六轴机械臂URDF魔改的，在仿真阶段gazebo中就出现了穿模和抖动的问题。

也有可能是3D打印的连杆太脆弱了总是晃。

## 尝试解决：

更换质量更好的硬件

## 最终解决方法：

视觉 STL 模型同时被当成碰撞模型，这在 Gazebo 里很容易炸，尤其当连杆是镂空结构、STL 细节多、部分模型还修改过。复杂三角网格碰撞可能发生自碰撞、穿插、接触抖动，物理引擎就会像“吹风”一样把连杆弹来弹去。

1. 保留 STL 外观不变

2. RViz / Gazebo 里看到的模型还是原来的机械臂。

3. 把 collision 从 STL 改成简单几何体

4. base 用 cylinder，连杆用 box。这样 Gazebo 物理稳定很多。

5. 给关节加阻尼，调软 Gazebo 控制器
