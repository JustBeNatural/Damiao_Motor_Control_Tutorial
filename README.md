# Damiao Motor Control Tutorial

达妙电机入门体验与控制教程。

本仓库主要记录我在自学和调试达妙 DM 系列电机过程中的学习笔记、使用教程和实践经验。内容包括达妙电机基础知识、通信协议、机器人运动学、URDF 建模、末端位姿解算，以及三轴机械臂键盘控制和多机协同控制等示例。我使用的是DM-J4310-2EC和DM-J4340-2EC型号电机，Ubuntu22.04环境。

这个仓库不是官方文档，而是一个面向初学者的个人学习总结，希望能帮助刚接触达妙电机、机械臂控制和机器人基础知识的同学少踩坑、快速入门。

---

## 项目简介

在学习达妙电机和机械臂控制的过程中，我发现很多资料比较分散，初学者经常会遇到以下问题：

* 不知道达妙电机的基本使用流程；
* 不清楚通信协议和电机控制之间的关系；
* 对机械臂运动学、URDF、末端位姿解算等概念比较陌生；
* 看懂了理论，但不知道如何结合实际电机做控制实验；
* 调试过程中遇到问题，不知道从哪里排查。

因此，我整理了这个仓库，用来记录达妙电机入门学习过程中的知识点、教程和代码示例。

## 免责声明

本仓库内容主要来自个人学习、实验和调试记录，仅供学习交流使用。由于不同电机型号、固件版本、SDK 版本和硬件连接方式可能存在差异，实际使用时请结合官方文档和自己的硬件环境进行验证。
