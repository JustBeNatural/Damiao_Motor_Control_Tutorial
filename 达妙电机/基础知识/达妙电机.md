## 7种转动控制方式：

| MIT模式 | 位置速度模式 | 速度模式 | PVT模式 | 周期位置模式 | 周期速度模式 |
| ------- | ------------ | -------- | ------- | ------------ | ------------ |

#### MIT模式（基于力矩控制的混合控制模式）

这个模式下可以同时控制位置，速度和力矩，本质上是一个PD控制+前馈力矩。控制输入一般有五个参数。 $$\tau = K_p (q_{\text{des}} - q) + K_d (\dot{q}_{\text{des}} - \dot{q}) + \tau_{ff$$

#### 位置速度模式

这个模式下可以设定电机转动的终止位置，和电机转动速度。只有两个控制参数，比较方便，适合初学。

| 参数   | 含义     | 单位       | 作用           |
| ------ | -------- | ---------- | -------------- |
| q_des  | 目标位置 | rad        | 你想让电机到哪 |
| dq_des | 目标速度 | rad/s      | 希望运动多快   |
| Kp     | 位置刚度 | Nm/rad     | “拉回去”的力度 |
| Kd     | 阻尼系数 | Nm/(rad/s) | 抑制震荡       |
| tau_ff | 前馈力矩 | Nm         | 直接施加力     |

### Kp（刚度）

-  越大 → 越“硬”，更快回到目标位置 
-  太大 → 会抖 / 震荡

### Kd（阻尼）

-  越大 → 更稳，不容易震荡 
-  太大 → 动作变慢、发闷

### dq_des（目标速度）

-  设为0 → 标准位置控制 
-  非0 → 做轨迹跟踪

### tau_ff（前馈力矩）

-  用于： 
  -  重力补偿 
  -  负载补偿 
-  不用可以填0
- `void Motor_Control::control_mit(Motor & motor, float kp, float kd, float q, float dq, float tau)`
