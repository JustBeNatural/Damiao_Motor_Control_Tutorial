## 尝试解决：

1. 怀疑是J4340不支持新版固件，无法使用

   ```
   dm.enable(M1)
   ```

   进行使能，必须转为旧版本固件SDK：

   ```
   dm.enable_old(M1, damiao::MIT_MODE)
   ```

   （虽然官方文档写着新版本固件是兼容旧版本的）

2. 怀疑代码写错了，接线没接对，虚拟机的问题......

3. 怀疑当前的新SDK仍然不支持最新的电机固件：
